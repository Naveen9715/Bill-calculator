# 💡 Android Utility Bill Calculator

An Android mobile application for calculating utility and electricity billing metrics based on user consumption units, with integrated SMS notification capabilities.

## 📱 Features

- **Dynamic Bill Computation**: Computes progressive billing tiers according to entered consumption units.
- **SMS Telephony Integration**: Utilizes Android SmsManager to send billing summaries to customer mobile numbers.
- **Interactive UI**: Built with native Android widgets (EditText, TextView, Button).

## 🛠️ Tech Stack

- **OS**: Android
- **Language**: Java
- **UI**: Android XML Layout
- **Libraries**: Android Support / AppCompat Library
